الموقع الإلكتروني والكتالوج الرسمي لـ **مول الشناوي للأجهزة الكهربائية والمنزلية** (فرع السنطة – محافظة الغربية). صُمم الموقع ليعكس الهوية البصرية الحقيقية لواجهة المحل بالألوان الملكية (الأزرق الملكي والذهبي الفاخر)، مع توفير تجربة تسوق واستفسار سريعة ومريحة لجميع العملاء عبر الهاتف والواتساب، بالإضافة إلى لوحة تحكم مدمجة للمشرفين.

## ✨ المميزات الرئيسية (Key Features)

1. **كتالوج الأجهزة والمنتجات التفاعلي:**
   - تصفح أقسام الأجهزة: الثلاجات، الغسالات، البوتاجازات، التكييفات، الشاشات والتلفزيونات، الأجهزة الصغيرة، والأدوات المنزلية.
   - فلترة لحظية وتصميم بطاقات احترافي يعرض تفاصيل ومواصفات كل جهاز.
   - زر مباشر **"اطلب عبر واتساب"** يقوم بتجهيز رسالة استفسار مخصصة باسم الجهاز ومواصفاته بضغطة واحدة.

2. **معرض الصور الحقيقي (Lightbox Gallery):**
   - صور عالية الجودة للأجهزة والمعروضات من أرض الواقع.
   - عارض صور مكبر (Lightbox) متجاوب يدعم التنقل بين الصور والأسهم ولوحة المفاتيح.

3. **لوحة تحكم المشرف (Admin Portal):**
   - محمية برمز حماية سري **PIN** (الرمز الافتراضي: `0000`).
   - إمكانية إضافة منتجات جديدة، تعديل بيانات أي منتج، أو حذفه فورياً.
   - زر دخول سريع تجريبي لتسهيل المعاينة.
   - إمكانية تغيير وتخصيص رمز الـ PIN وحفظه محلياً في المتصفح.

4. **تجاوب كامل وأداء فائق السرعة:**
   - مبني بالكامل بأحدث معايير الويب الخفيفة والسريعة دون ثقل أو بطء.
   - متوافق 100% مع جميع الهواتف الذكية (iOS و Android) والحواسيب والأجهزة اللوحية.

5. **فحص آلي واختبارات برمجية شاملة (Automated Tests):**
   - 16 اختباراً برمجياً موثقاً عبر `node:test` للتأكد من سلامة منطق الفلترة والتحقق والأرقام وإدارة المنتجات.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **المحرك:** [Vite](https://vitejs.dev/) لأسرع أداء أثناء التطوير والتجميع.
- **اللغات:** TypeScript / JavaScript (ESNext)، HTML5 دلالي، CSS3 متقدم.
- **التصميم:** Tailwind CSS مع نظام تصميم مخصص للألوان والخطوط العربية.
- **الأيقونات:** Lucide Icons & SVG مخصصة.
- **الاختبارات:** Node.js Native Test Runner (`tsx --test`).
- **التكامل المستمر:** GitHub Actions CI.

## 🚀 التشغيل محلياً على جهازك (Local Development)

### المتطلبات الأساسية (Prerequisites)
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو 20+ مفضل).
- تثبيت [Git](https://git-scm.com/).

### خطوات التثبيت والتشغيل:

```bash
# 1. استنساخ المستودع (Clone)
git clone https://github.com/USERNAME/REPO_NAME.git
cd REPO_NAME

# 2. تثبيت الحزم والمكتبات (Install Dependencies)
npm install

# 3. تشغيل خادم التطوير المحلي (Start Dev Server)
npm run dev
```

افتح المتصفح على الرابط: `http://localhost:3000`

## 📦 كيفية رفع المشروع على GitHub لأول مرة (Pushing to GitHub)

اتبع هذه الخطوات البسيطة لرفع المشروع إلى حسابك على GitHub:

```bash
# 1. تهيئة مستودع Git محلي (إذا لم يكن مهيئاً)
git init

# 2. إضافة جميع الملفات إلى التتبع
git add .

# 3. حفظ أول Commit
git commit -m "feat: الموقع الرسمي لمول الشناوي للأجهزة الكهربائية - فرع السنطة"

# 4. تعيين الفرع الرئيسي باسم main
git branch -M main

# 5. ربط المستودع برابط مستودعك الجديد على GitHub
# (استبدل YOUR_USERNAME و YOUR_REPO_NAME ببيانات حسابك)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

# 6. رفع الكود إلى GitHub
git push -u origin main
```

## 🌐 نشر الموقع مجاناً على GitHub Pages

يمكنك نشر الموقع ليعمل كـ رابط مباشر أونلاين مجاناً عبر **GitHub Pages**:

1. افتح مستودعك على **GitHub**.
2. اذهب إلى التبويب **Settings** ثم اختر من القائمة الجانبية **Pages**.
3. تحت قسم **Build and deployment**:
   - اختر **Source**: `GitHub Actions` أو `Deploy from a branch`.
   - عند اختيار **GitHub Actions**، يمكنك استخدام workflow لبناء `npm run build` ونشر مجلد `dist/` تلقائياً مع كل push.
   - أو يمكنك تشغيل `npm run build` محلياً ونشر مجلد `dist` على فرع `gh-pages`.
